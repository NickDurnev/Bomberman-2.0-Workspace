# Pull Request Conventions

- One PR per child repo. The base branch is `dev`.
- Fill the repo's `pull_request_template.md`.
- Write the title and body as if authored by the developer.
- Summarize what changed and why. Focus on the code and the problem it solves.
- Follow the style of recent PRs in the repository.
- Keep it concise and reviewer-oriented. Link related issues.
- Cross-repo feature: each PR links the other. Merge the backend PR first.
- Do not merge. The maintainer merges.

## No AI attribution

Do NOT include any AI or assistant attribution, such as:

- "Created by Claude" or "Generated with Claude Code"
- "Generated with ..." footers
- "Co-Authored-By: Claude ..." trailers
- any other reference to Claude, Anthropic or an AI assistant
